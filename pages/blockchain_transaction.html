Per-input MLSAG ring signatures. Each signature carries an initial challenge c0 and a flat ss array laid out as alternating spend / commitment scalars for every ring member.

Per-output Groth–Kohlweiss denomination membership proofs. Each proof binds the output commitment to one of the canonical bucket amounts without revealing which one.

The transaction kernel proves the balance equation ΣCin − ΣCout − fee·H = excess·G via a Schnorr signature over the excess commitment.
